# ISG Explorer

Interactive web application for exploring basal gene expression and
interferon inducibility across mammalian cell lines.

## Features

- IFN Landscape plot
- Expression matrix
- Top expressing DepMap cell lines
- Interactive Plotly visualisations
- PDF report generation

## Data Sources

- Broad Institute DepMap
- Centre for Virus Research ISG Database

## Running locally

```bash
pip install -r requirements.txt
streamlit run app.py
